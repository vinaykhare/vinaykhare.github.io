# AGENTS.md

## Repository Overview
Personal Portfolio and Resume website for Vinay Khare (Senior OSS/BSS Solution Architect & Technical Product Analyst / Flutter Developer). 
This repository contains a static HTML/CSS/JS portfolio site with multiple landing/privacy pages and downloadable resume assets.

## Structure & Entrypoints
- `index.html`: Main portfolio landing page.
- `resume.html`: Professional resume page.
- `css/boot.css`, `css/resume.css`: Custom stylesheets using Bootstrap 5.3.8 and Google Fonts.
- `js/boot.js`, `js/resume.js`: Frontend logic.
- `workoutminds/` & `chainplay/`: Sub-pages and privacy policy pages for mobile apps.
- `assets/`: Images, icons, PDFs, and resume Word/PDF documents.

## Local Development & Preview
- Static site: Open `index.html` directly in a browser or serve using any static HTTP server (e.g., `npx http-server`, Python `http.server`).
- There are no backend build steps, package managers (npm/yarn/pnpm), or automated tests configured in this repository.
